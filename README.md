賃貸物件データ収集スクリプト(Python)

矢島不動産の物件情報サイトから、賃貸物件の情報(物件名・賃料・所在地・間取り・詳細URL)を自動収集し、Excelファイルとして出力するスクレイピングツールです。

使用技術: Python, BeautifulSoup, pandas, openpyxl, requests
主な機能:
複数ページにわたる物件一覧の自動取得
詳細ページから正確な住所情報を補完取得
取得データをExcelに整形(見出しの色付け、罫線、列幅自動調整など)
フォルダ: ポートフォリオ/
